# Google Drive setup

The current decision is **MegaApp on GitHub Pages, Google Drive for asset files**. Reading connects directly from Safari or Chrome with a short-lived browser token and limited `drive.file` permission. No MacBook or custom cloud server is required.

See [PDF library, setup and security](pdf-library.md) and the [in-app storage guide](../reading/drive-guide.html). The earlier broker/cloud-host plan is superseded and retained privately for historical context.
