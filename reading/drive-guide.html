Your papers have a home.

MegaApp runs on GitHub Pages. Google Drive holds the actual PDF files. Your browser keeps cached copies for offline reading. These are separate jobs.

Try it on two devices

  1. Add a PDF, or use the two-page sample.
  2. Connect Drive, then sign in to Google. Upload the PDF.
  3. On your other device, open Reading and connect the same Google account.
  4. Refresh the library. Choose the cloud PDF to download and read it.
Refresh and upload happen while the app is open. Page position stays on this device for now. Cached PDFs work offline after the shell is prepared; browser storage can still be evicted.

One-time Google setup

In the dedicated MegaApp Google Cloud project, enable Drive API (already done), configure the OAuth testing audience, add your account as a test user, and create a Web application OAuth client. There is no backend or paid developer enrollment required.

Register this JavaScript origin, without a path:

https://mannyfluss.github.io

Enter the public client ID in Reading’s Connection setup, or let the project maintainer set it once for the deployed app. A school-managed account may need administrator approval. You can use a personal Google account with Drive.

Never enter a client secret, password, access token or private API key. The client ID is public. Google handles sign-in in its own popup.

Small permission, visible files

The app requests drive.file, allowing files created or selected for this app. It does not ask to browse your entire Drive. Uploaded PDFs are normal visible Drive files, tagged for this library.

Google also has a hidden appDataFolder for configuration. This sample uses normal files because papers are assets you should be able to see and manage.

What stays where

  • Drive: complete original PDFs, after a confirmed upload.
  • This browser: cached PDF bytes and reading position. Up to 25 MB per PDF and 100 MB total in this prototype.
  • Memory only: short-lived sign-in tokens. Reload requires reconnecting.
  • Configuration: small preferences and file references. No large PDF bytes or secret keys in State.

The reader never overwrites or deletes a Drive file. Disconnect forgets its local token; it keeps cached papers. Revoke the app’s access in your Google account to remove its grant everywhere.

Other code on MegaApp’s browser origin shares its trust boundary. Untrusted generated apps will need stronger isolation before they run there.
